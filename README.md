# twigs-site

Public pages for the [Twigs](https://github.com/elliottgriff) iOS app, served by GitHub Pages at
<https://elliottgriff.github.io/twigs-site/>.

- `oauth/client-metadata.json` is Twigs' Bluesky OAuth client metadata. Its URL is the app's `client_id`, so
  **the file must stay at this path**, and `client_id` inside it must match that URL exactly.
- `privacy.html` is the App Store privacy policy.
